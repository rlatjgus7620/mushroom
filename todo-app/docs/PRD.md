# PRD - Todo App (초안)

> 근거 문서: docs/IDEA.md
> 상태: 초안 (검토 필요)

## 1. 목표

혼자 쓰는 간단한 할 일 목록 웹 앱을 만든다.

- 사용자가 할 일을 빠르게 적고, 확인하고, 완료 처리하고, 지울 수 있다.
- 새로고침하거나 브라우저를 다시 열어도 데이터가 사라지지 않는다.
- 기능을 최소한으로 유지해 버전 로드맵(v0.1 → v1.0)을 단계적으로 완성한다.

## 2. 대상 사용자

- **개인 사용자 1명**: 자신의 할 일을 가볍게 관리하고 싶은 사람
- 로그인 없이 바로 사용하며, 다른 사람과 목록을 공유하지 않는다.

## 3. 기능 목록

| ID | 기능 | 설명 | 도입 버전 |
|------|------|------|------|
| F-01 | 할 일 추가 | 제목을 입력해 할 일을 추가한다. 제목은 필수이며 1~100자. | v0.1 |
| F-02 | 할 일 목록 보기 | 할 일을 최신순(최근 추가한 것이 위)으로 보여준다. | v0.1 |
| F-03 | 완료/미완료 전환 | 체크박스로 할 일의 완료 상태를 바꾼다. | v0.1 |
| F-04 | 할 일 삭제 | 할 일을 목록에서 삭제한다. | v0.1 |
| F-05 | 데이터 유지 | 새로고침해도 할 일 데이터가 유지된다. | v0.2(서버 메모리) → v0.3(DB) |

> F-01 ~ F-05가 MVP 범위다.

### 3.1 기능별 규칙

- **F-01 할 일 추가**
  - 제목이 비어 있으면 추가되지 않고 안내 메시지를 보여준다.
  - 제목이 100자를 넘으면 추가되지 않고 안내 메시지를 보여준다.
  - 제목 앞뒤 공백은 잘라내고 저장한다. 잘라낸 뒤 비어 있으면(예: `"   "`) 빈 제목으로 본다.
  - 제목 길이(1~100자)는 앞뒤 공백을 잘라낸 뒤 기준으로 센다.
  - 새 할 일은 '미완료' 상태로 만들어진다.
- **F-02 할 일 목록 보기**
  - 정렬 기준은 생성 시각 내림차순이다.
  - 할 일이 하나도 없으면 빈 상태 안내를 보여준다.
- **F-03 완료/미완료 전환**
  - 체크박스를 누를 때마다 완료 ↔ 미완료가 바뀐다.
  - 완료된 할 일은 화면에서 구분되어 보인다.
- **F-04 할 일 삭제**
  - 삭제한 할 일은 목록에서 즉시 사라진다.
- **F-05 데이터 유지**
  - v0.1은 브라우저 메모리만 사용하므로 새로고침 시 데이터가 사라진다. (예상된 동작)
  - v0.2부터 서버에 저장하고, v0.3부터 DB에 영구 저장한다.

## 4. 사용자 스토리

| ID | 관련 기능 | 사용자 스토리 |
|------|------|------|
| US-01 | F-01 | 사용자로서, 떠오른 할 일을 제목만 입력해 바로 추가하고 싶다. 그래야 잊어버리지 않는다. |
| US-02 | F-01 | 사용자로서, 제목을 비우거나 너무 길게 쓰면 알려줬으면 좋겠다. 그래야 잘못된 할 일이 생기지 않는다. |
| US-03 | F-02 | 사용자로서, 최근에 추가한 할 일을 맨 위에서 보고 싶다. 그래야 방금 적은 일을 바로 확인할 수 있다. |
| US-04 | F-03 | 사용자로서, 끝낸 일을 체크박스로 완료 표시하고 싶다. 그래야 남은 일과 끝낸 일을 구분할 수 있다. |
| US-05 | F-03 | 사용자로서, 실수로 완료 표시한 일을 다시 미완료로 되돌리고 싶다. |
| US-06 | F-04 | 사용자로서, 더 이상 필요 없는 할 일을 삭제하고 싶다. 그래야 목록이 깔끔하게 유지된다. |
| US-07 | F-05 | 사용자로서, 새로고침하거나 다시 접속해도 내 할 일이 그대로 남아 있었으면 좋겠다. |

## 6. 성공 기준

### 6.1 MVP (F-01 ~ F-05)

- [ ] 1~100자 제목으로 할 일을 추가할 수 있다.
- [ ] 빈 제목 또는 101자 이상 제목은 추가되지 않고 안내 메시지가 보인다.
- [ ] 목록이 최신순으로 표시된다.
- [ ] 체크박스로 완료/미완료를 반복 전환할 수 있다.
- [ ] 할 일을 삭제하면 목록에서 사라진다.
- [ ] (v0.3 이후) 새로고침, 브라우저 재시작, 서버 재시작 후에도 데이터가 유지된다.
- [ ] 각 기능에 대한 테스트가 통과한다.

### 6.2 버전별 완료 조건

| 버전 | 완료 조건 |
|------|------|
| v0.1 | F-01 ~ F-04가 브라우저 메모리에서 동작한다. |
| v0.2 | F-01 ~ F-04가 API를 통해 동작하고, 새로고침해도 데이터가 유지된다(서버 실행 중 한정). |
| v0.3 | 데이터가 DB에 저장되어 서버를 재시작해도 유지된다. |
| v0.4 | 필터와 수정 기능이 동작한다. (기능 명세는 추후 추가) |
| v1.0 | 앱이 배포되어 외부 URL로 접속해 MVP 전체를 사용할 수 있다. |
